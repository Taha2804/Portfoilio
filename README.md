# Taha Badami — Security Portfolio

A cybersecurity-focused portfolio website built with React, Framer Motion, and Tailwind CSS. Features a dark/hacker-inspired aesthetic with neon accents, an interactive terminal sidebar, and full scroll animations.

## Tech Stack

- **React 18** — UI framework
- **Vite** — Build tool
- **Tailwind CSS** — Utility-first styling
- **Framer Motion** — Animations
- **Lucide React** — Icons

## Features

- 🖥️ Interactive terminal sidebar with command parsing
- ✨ Scroll-triggered animations throughout
- 🎨 Dark theme with neon cyan, magenta, and purple accents
- 📱 Fully responsive design
- ⌨️ Typewriter, glitch, and hover effects
- 📊 Animated skill progress bars
- 📜 Vertical timeline for experience

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view.

## Build

```bash
npm run build
npm run preview
```

## Deploy

Configured for Vercel. Push to GitHub and connect to Vercel for automatic deploys.
